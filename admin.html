All orders

Everything clients have submitted, as they submitted it. Status is whether you've taken the order — confirming one sets it to Accepted for you, so the dropdown is really there for turning work down. Price Quote starts on the estimate the client was shown; edit it before you confirm and that figure carries through. Delete removes an order for good, along with its confirmed record if it has one.

Confirmed orders

Orders whose price has been agreed with the client. The four steps are tracked independently — tick them off as the job moves. An order printed unsleeved has no sleeving step, so its Cut and sleeved box is ticked and locked. Delete here removes only this record: the order returns to the table above, unconfirmed, and can be confirmed again.
